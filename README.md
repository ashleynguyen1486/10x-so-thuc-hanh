# Sổ thực hành – 10X Excellence Hub

Kho này chứa nội dung "Sổ thực hành" hiển thị tại https://10xexcellence.co/so-thuc-hanh. Trang web đọc trực tiếp các file trên nhánh `main`:

- `sth.js`: mã hiển thị (tải qua cdn.jsdelivr.net).
- `weeks.json`: danh sách các tuần. Mỗi tuần gồm:
  - `id`: mã tuần (ví dụ `0021`)
  - `label`: tên hiển thị (ví dụ `Tuần 1`)
  - `file`: tên file nội dung tuần (ví dụ `0021.json`)
  - `show`: ngày bắt đầu hiện tuần đó (định dạng `YYYY-MM-DD`)
- Các file tuần (ví dụ `0021.json`): mỗi file chứa nội dung 7 ngày của tuần.

`weeks.json` và các file tuần được tải qua raw.githubusercontent.com.
